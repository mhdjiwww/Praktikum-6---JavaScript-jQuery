# Praktikum 6 Pemrograman Web
## 1.Jelaskan secara singkat apa itu JavaScript dan kegunaannya
    JavaScript adalah bahasa pemrograman tingkat tinggi yang awalnya diciptakan untuk membuat halaman web menjadi interaktif dan dinamis. Jika HTML berfungsi sebagai kerangka dan CSS sebagai tampilannya, maka JavaScript sebagai otak atau logika yang mengatur pergerakan halaman web.

## 2.  Jelaskan secara singkat apa itu jQuery dan kegunaannya
    JQuery adalah pustaka JavaScript open source yang berfungsi untuk menyederhanakan penulisan kode JavaScript standar yang panjang dan rumit menjadi sintaks yang jauh lebih ringkas serta mudah dibaca. Adapun salah satu kegunaan utama JQuery yaitu memudahkan kita dalam penyederhanaan aksi pengguna, seperti tombol .click(), arah kursor mouse atau .hover()

## 3. Jelaskan perbedaan JavaScript dan jQuery
    Perbedaan JavaScript dan JQuery yaitu JavaScript adalah bahasa pemrograman mandiri sedangkan jQuery adalah library tambahan berbasis JavaScript. Berdasarkan dependensinya, JavaScript berjalan langsung di peramban tanpa perlu berkas atau pustaka tambahan, sedangkan jQuery membutuhkan tautan CDN eksternal agar kodenya bisa berjalan. Berdasarkan sintaksnya, JavaScript cenderung lebih panjang dan eksplisit, sedangkan jQuery jauh lebih ringkas dan kalau berdasarkan penggunaannya, JavaScript bisa digunakan untuk antarmuka web, logika sisi server, hingga aplikasi seluler sedangkan jQuery terbatas untuk penyederhanaan animasi antarmuka.
